Get started

From nothing to “open YouTube on my phone” in about five minutes. Every command on this page has a copy button.

What you need

An Android phoneAndroid 5.0 or newer, any brand
A computerWindows, macOS or Linux with Node.js 20+
A USB cableOnly for the first install
An AI agentClaude Code, Cursor, Antigravity or any MCP client

1 · Install the app

Recommended: over USB. On the phone, open Settings → About phone and tap Build number seven times. Then go to Settings → Developer options and turn on USB debugging. Plug the phone in and run:

$npx android-agent-bridge usb

This installs the app, switches on its accessibility service, pairs it and starts the bridge. Accept the “Allow USB debugging?” prompt on the phone. You can skip step 2.

No cable? Over Wi-Fi (Android 11+): in Developer options turn on Wireless debugging, run this, then tap Pair device with QR code on the phone and scan the code in your terminal.

$npx android-agent-bridge wifi

Both commands fetch Google's adb tool the first time if your computer doesn't have it.

Why not the APK? Google Play Protect blocks sideloaded apps that use the accessibility service when they're opened from a browser or chat app (“App blocked to protect your device”). Installing from your computer isn't affected. If your phone allows it, the APK (13 MB) works too.

2 · Start and pair

Skip this if you used usb. Otherwise, with the phone and computer on the same Wi-Fi:

$npx android-agent-bridge start
  1. Open Agent Bridge on the phone and tap Scan QR code.
  2. Point the camera at the QR code in your terminal, or the bigger one at localhost:8350/pair.
  3. Tap Accessibility service → Turn on in the app and switch Agent Bridge on.

The app remembers your computer and reconnects by itself. On Windows, allow Node.js through the firewall when asked.

3 · Connect your agent

Claude Code:

$claude mcp add phone -- npx -y android-agent-bridge

Any project (writes .mcp.json and a short agent guide):

$npx android-agent-bridge init

Cursor, Antigravity, Windsurf and other MCP clients: add this to the client's MCP config file (Cursor: .cursor/mcp.json).

mcp.json
{
  "mcpServers": {
    "phone": { "command": "npx", "args": ["-y", "android-agent-bridge"] }
  }
}

Restart the agent after adding it. It gets 27 tools such as phone_screen, phone_tap and phone_type, plus the prompts below.

4 · Check it works

Ask your agent:

Or from a terminal: install the short command once, then check the status.

$npm i -g android-agent-bridge
$phonectl status

Built-in MCP prompts

The MCP server also ships ready-made prompts. In Claude Code they're slash commands: type /mcp__phone__ to see them. Other clients list them in their prompt menu.

Slash commandAsks forWhat it does
/mcp__phone__phone_tournothingConfirms the phone is connected and describes the screen.
/mcp__phone__do_in_appapp, taskOpens an app and carries out a task step by step.
/mcp__phone__test_my_appapp, focus?QA walkthrough with a bug report at the end.
/mcp__phone__catch_upnothingSummarises notifications, urgent first.
/mcp__phone__set_up_phonesettingsVolume, brightness, Do Not Disturb in one go.
/mcp__phone__send_to_phonefilesSends files and confirms where they landed.

Command cheat sheet

Everything an agent can do, you can do from a terminal. phonectl comes with npm i -g android-agent-bridge; without it, use npx android-agent-bridge. Keep start running in another terminal.

Set up

npx android-agent-bridge usbInstall the app over USB, switch it on, pair, start
npx android-agent-bridge startStart the bridge and show the pairing QR code
npx android-agent-bridge initAdd the MCP server to this project
phonectl statusIs the phone connected?

Look and act

phonectl screen --out shot.jpgScreenshot with numbered elements
phonectl elementsNumbered list of what's on screen
phonectl tap 12Tap element 12 (or "Sign in", C7, 540,1200)
phonectl type "hello" --into 5 --submitType into a field and press Enter
phonectl scroll downScroll the main list
phonectl key backback, home, recents, notifications

Apps and device

phonectl launch YouTubeOpen an app by name
phonectl volume 40%Media volume (ring, alarm, …)
phonectl brightness 70Screen brightness, or auto
phonectl dnd onDo Not Disturb
phonectl batteryBattery level and charging

Files

phonectl send photo.jpgSend to the phone's Downloads/Agent Bridge
phonectl receivedFiles the phone sent to this computer
phonectl dropDrag-and-drop page in the browser

Every command, with all its options, is in the full command reference.

If something's wrong

  • “App blocked to protect your device”: install over USB with npx android-agent-bridge usb.
  • The agent says no phone is connected: is start (or usb) running? Same Wi-Fi? Is the accessibility service on in the app?
  • Accessibility switch is greyed out (Android 13+): App info → ⋮ → Allow restricted settings, then try again.
  • Screenshots are black: that app blocks screen capture (banking, video). The agent can still read the element list.
