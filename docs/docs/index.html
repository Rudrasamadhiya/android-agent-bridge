Documentation

Every command works from a terminal and as an MCP tool. Keep start running in one terminal and run the rest in another.

Quick start

  1. Install the app. Turn on USB debugging, plug the phone in and run:
    $npx android-agent-bridge usb
  2. Start the bridge whenever you want the agent to have the phone:
    $npx android-agent-bridge start
  3. Connect your agent. In your project folder:
    $npx android-agent-bridge init
    For Claude Code you can also run claude mcp add phone -- npx -y android-agent-bridge.

Installation

The computer side needs Node.js 20 or newer. Run it with npx every time, or install it once to get the short phonectl command:

$npm i -g android-agent-bridge

The phone side is the Agent Bridge app (Android 5.0+). Install it with usb as above, or download the APK. After installing, Android asks you to switch on the Agent Bridge accessibility service; the app walks you there.

Pairing

Wi-Fi: phonectl and computer on the same network or hotspot. Run start, open the app, tap Scan and point it at the QR code. The app remembers the computer and reconnects by itself.

USB: usb sets up an adb tunnel, so no QR is needed and it works without Wi-Fi. On Windows, allow Node.js through the firewall the first time for Wi-Fi.

Targets

Commands that act on something take a target in one of four forms:

TargetMeaning
12Element number from the latest element list. The most reliable.
"Sign in"Visible text. The app's own controls win over the Android system bar, and text the app hides from accessibility is found by reading the screen.
C7A grid cell from screen --mode grid, for maps, games and images.
540,1200Screen pixels.

Commands

The examples use phonectl, which you get from the global install. With npx, write npx android-agent-bridge instead.

Setup

CommandWhat it does
phonectl startRuns the bridge and prints the QR code to scan. A bigger one is at localhost:8350/pair.
phonectl usbFor a phone plugged in with USB debugging: installs the app, turns it on, pairs and runs the bridge. No QR code.
phonectl initAdds the MCP server to .mcp.json and a short agent guide to the current project.
phonectl pairShows the QR code again. --reset makes a new secret; every phone must scan again.
phonectl statusThe connected phone, how it is connected, and what it can do.
phonectl permissions grantOver USB, switches on the optional permissions: brightness, rotation, Do Not Disturb, saving to Downloads.

Look

CommandWhat it does
phonectl elementsNumbered list of what's on screen. --all includes elements covered by sheets; --ocr adds text read from the pixels.
phonectl screen --out shot.jpgScreenshot with every element boxed and numbered. --mode grid | both | plain.
phonectl ocrAll text drawn on screen, with positions.
phonectl currentThe app in front.
phonectl wait "Done"Waits until that text appears (--timeout 10000).

Act

CommandWhat it does
phonectl tap 12Taps a target. --long long-presses.
phonectl type "hello" --into 5Types into a field without the keyboard. --append keeps existing text, --submit presses Enter.
phonectl scroll downScrolls the main list. --in 3 picks a list, --amount 0.6 how far.
phonectl swipe 540,1800 540,400Drags from one target to another (--ms 300).
phonectl key backback, home, recents, notifications, quick_settings, enter, lock, power_dialog.

Apps & links

CommandWhat it does
phonectl launch UberOpens an app by name or package. --store opens its Play Store page if it isn't installed.
phonectl apps whatsInstalled apps, filtered.
phonectl url youtube.comOpens a web page or deep link (geo:, mailto:, myapp://).
phonectl search "weather"Web search on the phone.
phonectl store "Zepto"Play Store page or search.
phonectl dial 9876543210Opens the dialer with the number filled in. Never places the call.
phonectl stop com.exampleForce-stops an app (USB).

Device

CommandWhat it does
phonectl volume 40%Media volume. Streams: ring, notification, alarm, call, system. Actions: up, down, mute, unmute, max, a level or a percentage.
phonectl ringer vibratenormal, vibrate or silent.
phonectl brightness 700–100, auto or manual.
phonectl rotation autoauto, portrait or landscape.
phonectl flashlight onon or off.
phonectl dnd onDo Not Disturb: on, alarms, total, off.
phonectl settings wifiOpens a settings page: wifi, bluetooth, display, sound, battery, location, apps, developer and more.

phonectl notificationsNotifications received since the service started.
phonectl clipboard set "text"Sets the clipboard; without set it reads it.
phonectl wakeTurns the screen on. A PIN lock stays locked.

Transfer

CommandWhat it does
phonectl send a.pdf b.jpgSends files to the phone's Downloads/Agent Bridge.
phonectl receivedFiles the phone sent, and the folder they're in (Downloads/Agent Bridge on the computer).
phonectl dropPrints the drag-and-drop page address: http://localhost:8350/drop.

MCP tools

What your agent sees after init:

ToolPurpose
phone_statusConnection, model, Android version; pairing help if nothing is connected.
phone_elements · phone_screen · phone_ocrRead the screen as text, as a labelled screenshot, or from the pixels.
phone_tap · phone_type · phone_scroll · phone_swipe · phone_keyAct on the screen. Each returns the updated element list.
phone_open_app · phone_apps · phone_wait_forApps and waiting.
phone_volume · phone_brightness · phone_toggleSound, screen, flashlight, rotation, Do Not Disturb, ringer.
phone_settings · phone_open_link · phone_web_search · phone_dialJump to settings pages, links and the dialer.
phone_device_info · phone_notifications · phone_clipboard · phone_wakeStatus and small utilities.
phone_send_files · phone_received_filesFile transfer.
phone_permissions · phone_stop_appPermissions over USB, force-stopping apps.

Any MCP client works with this configuration:

{
  "mcpServers": {
    "phone": { "command": "npx", "args": ["-y", "android-agent-bridge"] }
  }
}

Troubleshooting

  • “App blocked to protect your device”: install over USB with phonectl usb.
  • No phone connected: is start running? Same Wi-Fi? On Windows, allow Node.js through the firewall. Over USB, run phonectl usb again to restore the tunnel.
  • Accessibility switch greyed out (Android 13+): App info → ⋮ → Allow restricted settings.
  • A tap opened nothing right after Home: Android holds app starts for about 5 seconds after Home. The commands retry, but run it again if needed.
  • Black screenshots: the app blocks capture (banking, video). Use elements instead.
