On your phone?

Scan with the phone's camera to download the APK directly.

Computer

Bridge & MCP server

Node.js 20 or newer on Windows, macOS or Linux. Nothing to install: run it with npx.

$npx android-agent-bridge start
$npm i -g android-agent-bridge

Install the app

A

Recommended: over USB

Turn on Developer options → USB debugging, plug the phone in, run this. It installs, enables and pairs in one go, and Play Protect won't block it.

$npx android-agent-bridge usb
B

Or from the APK

Open the downloaded file on the phone and allow installs from your browser. If Play Protect blocks it, use the USB route instead.

C

Then pair

Run start on the computer, open Agent Bridge, tap Scan and point it at the QR in your terminal.

$npx android-agent-bridge start

Older versions and release notes are on GitHub Releases.
