File 001 · Why this exists

Your agent can write code, search the web and run your terminal. It has never held a phone. Agent Bridge hands it yours. It reads the screen, taps, types, opens apps, turns the volume down and sends you the file. No emulator. No cloud. No account. One npx command and a QR code.

Quick start

Upintwominutes.

01

Install the app

Turn on USB debugging and plug in. The CLI installs the app and switches it on. Or download the APK.

$npx android-agent-bridge usb
02

Start the bridge

Open Agent Bridge on the phone and scan the QR. It reconnects by itself after that.

$npx android-agent-bridge start
03

Connect your agent

Add the MCP server, restart the agent and ask it to use the phone.

$npx android-agent-bridge init
terminal
claude mcp add phone -- npx -y android-agent-bridge

Security & privacy

Yourphone.Yourrules.

Paired, not public

Only a computer holding the secret from your QR code can connect. Make a new one any time with pair --reset.

Stays on your network

The phone talks to your computer over Wi-Fi or USB. No cloud, no account, no analytics.

On-device OCR

Text recognition runs on the phone. Screenshots go to your computer and nowhere else.

One switch to stop

Turn off the accessibility service and access ends at once. Forget the computer from the app.

Agents ask first

The bundled guide tells agents to ask before paying, posting, sending or deleting, and never to type passwords.

Open source, MIT

Every line of the app, bridge and MCP server is on GitHub. Read it, fork it, audit it.
