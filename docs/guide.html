Reference

Commands

Every command works from a terminal and as an MCP tool. Keep start running in one terminal; run the rest in another.

A shorter name

The examples use phone as short for the full command. Make it once per terminal:

PSfunction phone { npx -y github:Rudrasamadhiya/android-agent-bridge @args }
$alias phone='npx -y github:Rudrasamadhiya/android-agent-bridge'

The first is for Windows PowerShell, the second for macOS and Linux shells.

Setup

CommandWhat it does
phone startRuns the bridge and prints the QR code to scan. A bigger one is at localhost:8350/pair.
phone usbFor a phone plugged in with USB debugging: installs the app, turns it on, pairs, and runs the bridge. No QR code.
phone initAdds the MCP server to .mcp.json and a short agent guide to the current project.
phone pairShows the QR code again. --reset makes a new secret; every phone must scan again.
phone statusThe connected phone, how it is connected, and what it can do.
phone permissions grantOver USB, switches on the optional permissions (brightness, rotation, Do Not Disturb, saving to Downloads).

Targets

Commands that act on something take a target in one of four forms:

TargetMeaning
12Element number from the latest element list. The most reliable.
"Sign in"Visible text. The app's own controls win over the Android system bar, and text the app hides from accessibility is found by reading the screen.
C7A grid cell from screen --mode grid, for maps, games and images.
540,1200Screen pixels.

Look

CommandWhat it does

phone screen --out shot.jpgScreenshot with every element boxed and numbered. --mode grid|both|plain.
phone ocrAll text drawn on screen, with positions.
phone currentThe app in front.
phone wait "Done"Waits until that text appears (--timeout 10000).

Act

CommandWhat it does
phone tap 12Taps a target. --long long-presses.
phone type "hello" --into 5Types into a field without the keyboard. --append keeps existing text, --submit presses Enter.
phone scroll downScrolls the main list. --in 3 picks a list, --amount 0.6 how far.
phone swipe 540,1800 540,400Drags from one target to another (--ms 300).
phone key backback, home, recents, notifications, quick_settings, enter, lock, power_dialog.

Transfer

CommandWhat it does
phone send a.pdf b.jpgSends files to the phone's Downloads/Agent Bridge.
phone receivedFiles the phone sent, and the folder they're in (Downloads/Agent Bridge on the computer).
phone dropPrints the drag-and-drop page address: http://localhost:8350/drop.

On the phone: Agent Bridge → Transfer → Choose files, or Share → Agent Bridge from any app.

Troubleshooting

  • “App blocked to protect your device”: install over USB with phone usb.
  • No phone connected: is start running? Same Wi-Fi? On Windows, allow Node.js through the firewall. Over USB, run phone usb again to restore the tunnel.
  • Accessibility switch greyed out (Android 13+): App info → ⋮ → Allow restricted settings.
  • A tap opened nothing right after Home: Android holds app starts for ~5 seconds after Home; the commands retry, but run it again if needed.
  • Black screenshots: the app blocks capture (banking, video). Use elements instead.
